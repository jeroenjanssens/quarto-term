# Use Cases

- **CLI documentation** — build docs for a command-line tool showing real invocations with actual output
- **Installation guides** — beautifully show how to install an R or Python package, a Homebrew formula, or any tool
- **Shell tutorials** — teach bash/zsh concepts (pipes, redirection, loops) where seeing the prompt and typed commands is the point
- **TUI tutorials** — create interactive walkthroughs for fullscreen apps like htop, vim, or lazygit
- **DevOps runbooks** — show a realistic sequence of kubectl, docker, or terraform commands with state persisting across steps
- **Database workflow demos** — connect to SQLite/DuckDB/psql, create tables, insert data, query it in one persistent session
- **Dotfiles & environment setup guides** — show the full flow of configuring a development environment
- **Security/CTF writeups** — step through an exploit or analysis with colored tool output (nmap, gobuster, etc.)
- **Data pipeline walkthroughs** — show curl, jq, csvkit, duckdb chains where each step builds on the previous
- **Git workflow tutorials** — demonstrate branching, merging, rebasing with actual repo state carrying across cells
- **Comparing tools side-by-side** — show the same task in different shells with appropriate colorschemes and chrome styles
- **Technical books and courses** — anywhere you'd show "type this, see that" sequences with faithful terminal rendering
- **API exploration guides** — curl a REST API, pipe through jq, use the result in the next request
